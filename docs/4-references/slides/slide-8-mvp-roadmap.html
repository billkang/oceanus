开发阶段

Phase 1 平台搭建 — 脚手架 + Session/Chat API + SDK 集成 + 项目对话闭环
Phase 2 体验完善 — SSE 流式 + 前端聊天 UI + DeepStorm Skill 集成 + 资产提取
Phase 3 生态扩展 — 自定义 Skill + MCP 对接 + Langfuse 可观测 + LLM-as-Judge 评估

MVP 原则：核心链路（对话 → Agent → 产出 → 持久化）必须完整可运行。辅助能力框架到位不追求完美。
自定义 Skill 和 MCP 是平台从"工具"变成"平台"的关键。
