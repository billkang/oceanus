四个设计决策

1

选用成熟 Harness SDK

Harness Agent 是独立技术领域，不自研。Agent 循环、工具调用、上下文管理由 Claude Agent SDK 承载。

2

Skill 承载业务能力

业务能力不硬编码，而是沉淀为可复用的 Skill 文档。DeepStorm 提供基础 Skill 体系，用户基于其上构建自定义 Skill。

3

标准协议集成

外部能力通过 MCP 接入，流式事件通过 SSE 传输。

4

平台沉淀组织资产

文档、代码、Skill 等产研产出均在平台上创建和维护，作为组织级资产持续积累。
