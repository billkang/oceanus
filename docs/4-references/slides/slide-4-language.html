① Agent 框架选型

🤖 Claude Agent SDK ✅ 选择

  • ✅ DeepStorm 原生打通，改造成本最低
  • ✅ 能力最完善的 Harness SDK，原生 MCP
  • ✅ TS / Python 双语言支持
  • ✅ 文档完善，社区活跃

⚡ Pi（OpenClaw 核心引擎）

  • ⚡ 极简主义，77K+ Stars
  • ⚡ 无 MCP，"Code as Protocol"
  • ⚡ 需技术适配，不兼容 DeepStorm 生态
  • ⚡ 仅 TS，Python 需额外封装

② 语言选型

🟦 TypeScript ✅ 选择

Claude Agent SDK 首选语言

  • ✅ 全栈统一，学习成本最低
  • ✅ 前端 Angular + 后端 NestJS，同一语言栈
  • ✅ DeepStorm 基类可直接复用
  • ✅ 零技术调研成本，开箱即用

☕ Java

公司主力栈，团队最熟悉

  • ✗ Agent 生态较弱
  • ✗ 需从零调研方案、适配 DeepStorm
  • ✗ 时间成本高

🐍 Python

AI 时代第一语言

  • ✅ Claude Agent SDK 也支持 Python
  • ✗ 公司 Python 工程师较少

最终结论：不是"TS 比 Java 好"，而是 Agent 框架生态的先决条件。
Claude Agent SDK 原生 TypeScript + DeepStorm 基类可直接复用 → TypeScript 是适配成本最低 的选择。
