# 任务 013 — 用户确认交互组件（选项按钮 + 其他自由输入）

**Epic:** 前端页面开发
**优先级:** P0
**关联需求:** FR-10

---

## 描述

当 Claude Agent SDK 在执行 Tide-discuss 流程中需要用户确认或选择时，前端以交互式按钮的形式展示选项，同时提供"其他"按钮允许用户自由输入文本。

## 交互模式

SDK 触发确认事件 → SSE 推送工具确认 → 前端展示选项列表：

```
[系统消息]
请您选择：
┌─────────────┐ ┌─────────────┐ ┌──────────┐
│  选项 A      │ │  选项 B      │ │  其他...  │
└─────────────┘ └─────────────┘ └──────────┘
```

- 点击选项按钮 → 将选择发送回后端 → Agent 继续执行
- 点击"其他" → 展开文本输入框 → 用户输入自定义内容 → 发送

## 组件设计

在聊天消息流中渲染特殊类型的消息块（非普通文本气泡）：
- 确认消息块：显示提示文本 + 选项按钮组
- 按钮使用 PrimeNG Button，水平排列
- 选中后按钮变为已选状态，同时发送请求

## 验收标准

- [ ] SDK 推送确认事件后展示选项按钮
- [ ] 点击选项按钮后发送选择到后端
- [ ] "其他"按钮展开文本输入框
- [ ] 提交后按钮组切换为已提交状态
- [ ] SDK 返回处理后更新消息列表

## 技术要点

- 消息类型枚举需要扩展：`text | options | option_selected`
- 通过 `metadata.type` 字段区分消息类型
- SSE 事件中 `event: tool_use` 携带选项数据
