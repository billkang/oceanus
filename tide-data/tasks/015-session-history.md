# 任务 015 — 会话历史列表 + 删除操作

**Epic:** 前端页面开发
**优先级:** P0
**关联需求:** FR-4

---

## 描述

实现左侧面板的会话历史列表，展示当前项目下所有活跃会话，支持按时间倒序排列和删除操作。

**架构变更说明（2026-07-23）：** 原"归档"能力已取消，改为物理删除。删除时会级联清理 DB 记录 + SDK JSONL 文件。

## 页面要素

- 顶部："会话历史"标题 + 新建会话按钮
- 会话列表（按时间倒序）：
  - 会话标题（自动生成或基于讨论内容）
  - 最后消息时间
- 每个会话项的操作：
  - 删除按钮（垃圾桶图标）

## 交互细节

- 点击会话项切换当前会话
- 当前会话高亮标识
- 删除操作需二次确认弹窗（"删除后不可恢复，确认删除？"）
- 会话列表为空时显示空状态
- 新会话自动添加到列表顶部并选中

## 验收标准

- [ ] 会话列表按时间倒序展示
- [ ] 点击可切换会话
- [ ] 当前会话高亮
- [ ] 删除操作后会话从列表消失
- [ ] 删除前弹出确认提示
- [ ] 新建会话后自动出现
- [ ] 空状态展示

## 技术要点

- 使用 PrimeNG Listbox 或 Tree 组件
- 删除为物理删除（级联清理 DB + JSONL + SDK 实例），前端需二次确认
- 切换会话时通过路由参数或 Service 管理当前会话 ID
