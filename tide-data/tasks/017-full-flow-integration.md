## 描述

将前后端所有模块串联起来，打通完整的 PM 工作流程，确保 MVP 的 12 条验收标准全部通过。

## 联调流程

```
登录页 → 项目列表 → 创建项目
  → 自动进入项目 → 自动创建会话 → 自动启动 Tide-discuss
    → 用户与 AI 对话 → SSE 流式渲染
      → SDK 确认交互 → 用户选择 → AI 继续
        → 讨论完成 → PRD 自动提取到资产面板
          → 查看/下载/复制 PRD
```
