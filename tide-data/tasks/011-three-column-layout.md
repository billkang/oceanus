# 任务 011 — 三栏布局框架（会话历史/聊天/资产面板，可折叠）

**Epic:** 前端页面开发
**优先级:** P0
**关联需求:** FR-5

---

## 描述

实现项目工作区的三栏布局，这是 Oceanus 的核心界面框架。

## 布局结构

```
┌──────────┬────────────────────────────┬──────────┐
│   左侧    │           中间              │   右侧    │
│ 会话历史  │      聊天 + 输入框          │  资产面板  │
│ (可折叠)  │                            │ (可折叠)  │
│ 宽 280px  │        自适应               │ 宽 320px  │
└──────────┴────────────────────────────┴──────────┘
```

## 功能要点

- **左侧面板（会话历史）**
  - 默认展开，宽度 280px
  - 折叠按钮（箭头图标），折叠后仅显示图标
  - 包含新建会话按钮

- **中间区域（聊天）**
  - 占满剩余空间
  - 消息列表 + 底部输入框

- **右侧面板（资产面板）**
  - 默认展开，宽度 320px
  - 折叠按钮
  - 折叠时完全隐藏

## 验收标准

- [ ] 三栏布局正确渲染
- [ ] 左侧面板可折叠/展开
- [ ] 右侧面板可折叠/展开
- [ ] 左侧折叠后仍保留折叠/展开按钮
- [ ] 布局响应式自适应（PrimeNG 默认风格）

## 技术要点

- PrimeNG Panel 或 Splitter 组件实现
- 折叠状态存储在 SessionService（刷新保持）
- 折叠动画平滑过渡
