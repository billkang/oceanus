# 任务 012 — 聊天 UI — SSE 流式渲染 + AI 状态提示

**Epic:** 前端页面开发
**优先级:** P0
**关联需求:** FR-6, FR-9

---

## 描述

实现聊天界面的核心交互，包括消息展示、输入框、SSE 流式渲染和 AI 处理状态提示。

## 页面要素

### 消息列表
- 用户消息（右对齐，蓝色气泡）
- AI 消息（左对齐，灰色气泡）
- 流式渲染：AI 响应逐字/逐段追加显示
- 滚动到底部（新消息自动滚动）
- 加载历史消息（滚动到顶部触发）

### 输入框
- 底部固定输入区域（PrimeNG InputTextarea）
- 发送按钮
- 支持 Enter 发送（可配置 Shift+Enter 换行）
- 发送后清空输入框
- SDK 处理中禁用输入（等待响应完成）

### AI 状态提示
- 在消息列表中显示状态文字：
  - "正在分析需求…"
  - "正在生成 PRD…"
  - "等待您的选择…"
- 使用文字提示（非进度条）
- 多状态切换时更新文字

## 验收标准

- [ ] 用户消息可正常发送
- [ ] AI 响应流式渲染到聊天框
- [ ] 滚动到最新消息
- [ ] AI 处理中显示当前状态文字
- [ ] SDK 处理中禁用输入框
- [ ] 历史消息可滚动加载

## 技术要点

- 使用 Angular 的 `EventSource`（原生）连接 SSE
- 消息流式追加使用 `ChangeDetectorRef` 或 Signal 触发更新
- 消息列表使用虚拟滚动（如消息量不大可简单实现）
- SSE 断线后自动重连，重连后调用 REST API 补齐消息
