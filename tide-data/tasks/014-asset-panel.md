# 任务 014 — 资产面板 — PRD 查看/下载/复制

**Epic:** 前端页面开发
**优先级:** P0
**关联需求:** FR-8

---

## 描述

实现右侧资产面板，展示 Tide-discuss 讨论完成后生成的 PRD，支持查看、下载 Markdown 和复制内容。

## 页面要素

- 面板标题："资产"
- 资产列表（初始为空）
- 每个资产项显示：
  - 资产类型图标（PRD 显示 📄）
  - 资产标题
  - 创建时间
- 点击资产项 → 展开预览（内容以 Markdown 格式渲染）
- 预览区域顶部操作按钮：
  - 📋 复制内容（点击复制到剪贴板）
  - ⬇️ 下载为 Markdown（触发文件下载）

## 交互细节

- 新资产生成时资产面板自动刷新
- 空状态提示："暂无资产，完成需求讨论后将在这里展示"
- 预览区域支持滚动
- Markdown 渲染使用 PrimeNG 或简单格式化（不做复杂渲染）

## 验收标准

- [ ] 资产面板在右侧正确展示
- [ ] 初始状态显示空状态提示
- [ ] PRD 生成后自动出现在资产列表
- [ ] 点击可展开预览 PRD 内容
- [ ] 复制按钮可复制内容到剪贴板
- [ ] 下载按钮可下载为 `.md` 文件

## 技术要点

- 使用 PrimeNG Panel 作为面板容器
- SSE 事件中 `event: asset_created` 通知前端刷新
- 复制使用 `navigator.clipboard.writeText()`
- 下载使用 `Blob` + `URL.createObjectURL()` 触发下载
