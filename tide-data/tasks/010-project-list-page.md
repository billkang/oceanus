# 任务 010 — 项目列表页 + 创建项目弹窗

**Epic:** 前端页面开发
**优先级:** P0
**关联需求:** FR-2, FR-3

---

## 描述

实现项目列表页，展示用户所有项目。提供创建项目弹窗（Dialog），填写名称和备注即可创建。

## 页面要素

- 顶部导航栏（显示 Logo + 用户名 + 退出登录按钮）
- 项目卡片列表，每个卡片展示：
  - 项目名称
  - 备注（截断）
  - 会话数量
  - 最后更新时间
- 创建项目按钮（FAB 或顶部）
- 创建项目 Dialog（PrimeNG Dialog）：
  - 项目名称输入框（必填）
  - 备注文本域（可选）
  - 确认/取消按钮

## 交互细节

- 项目卡片点击后直接跳转到项目工作区
- 创建项目成功后自动跳转到新项目
- 项目列表为空时显示空状态提示

## 验收标准

- [ ] 登录后自动展示项目列表
- [ ] 项目卡片显示名称、备注、会话数、更新时间
- [ ] 创建项目 Dialog 正常打开，填写信息后创建成功
- [ ] 创建后自动跳转到项目
- [ ] 空列表时展示空状态

## 技术要点

- PrimeNG Card 组件展示项目
- PrimeNG Dialog 组件做创建弹窗
- 列表通过 Angular Service 调用后端 API
