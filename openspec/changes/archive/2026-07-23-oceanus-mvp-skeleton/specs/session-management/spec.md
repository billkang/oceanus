## ADDED Requirements

### Requirement: 创建会话
进入项目后系统自动创建一个新会话。会话标题默认使用用户输入的第一句话，后续由 LLM 摘要更新。

#### Scenario: 进入项目自动创建会话
- **WHEN** 用户进入项目工作区
- **THEN** 系统自动创建一个新会话，初始标题为"新会话"，并自动启动 Tide-discuss

#### Scenario: 标题随对话更新
- **WHEN** 用户输入第一句消息
- **THEN** 会话标题更新为该消息内容的前半段
- **WHEN** 讨论进行多轮后
- **THEN** LLM 生成会话摘要作为新标题

### Requirement: 会话历史列表
左侧面板展示当前项目下所有活跃会话，按时间倒序排列。

#### Scenario: 多会话列表展示
- **WHEN** 项目下有多个会话
- **THEN** 左侧面板按时间倒序显示所有会话（标题 + 最后消息时间）

#### Scenario: 切换会话
- **WHEN** 用户点击列表中的某个会话
- **THEN** 当前会话高亮，中间聊天面板加载该会话的聊天记录

#### Scenario: 空会话列表
- **WHEN** 项目下没有任何会话（全部已删除）
- **THEN** 展示空状态提示

### Requirement: 删除会话
用户可物理删除会话，级联清理数据库记录 + SDK JSONL 文件 + SDK Agent 实例。

#### Scenario: 删除前确认
- **WHEN** 用户点击删除按钮
- **THEN** 弹出二次确认弹窗："删除后会话记录和关联资产将永久清除，确认删除？"

#### Scenario: 确认删除
- **WHEN** 用户在确认弹窗中选择"确认删除"
- **THEN** 系统删除数据库记录、清理 SDK JSONL 文件、销毁 SDK Agent 实例，会话从列表中消失

#### Scenario: 取消删除
- **WHEN** 用户在确认弹窗中选择"取消"
- **THEN** 不执行任何删除操作，关闭弹窗
